MoleMix — Ионы-пазлы

Открой index.html в браузере, чтобы запустить тренажёр.
На начальной странице нажми «Начать».
Подключение к интернету для работы заданий не требуется.

Для GitHub Pages:
1. Распакуй ZIP.
2. Скопируй все файлы в нужную папку репозитория. index.html должен лежать
   в корне этой папки, рядом с styles.css и файлами JavaScript.
3. Сохрани изменения и отправь их через GitHub Desktop.

Как пользоваться:
— Перетащи ион из банка на поле. В банке остаётся образец: можно брать копии.
— Поднеси подходящий край к другому иону. Деталь примагнитится.
— Соединённые детали можно двигать вместе.
— Нажми на деталь, чтобы отсоединить или убрать её.
— Нажми «Проверить». При ошибке измени сборку и проверь снова.
— При правильном ответе появится диссоциация и кнопка перехода дальше.

Также можно добавлять ионы нажатием на банк. Для управления с клавиатуры:
Tab — выбрать деталь, стрелки — двигать, Enter — соединить,
Delete — убрать. На телефоне банк ионов прокручивается по вертикали.
